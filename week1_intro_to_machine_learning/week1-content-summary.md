
### Week 1 — Introduction to Machine Learning

> [!info] Week Objective
> Build a clear conceptual understanding of Machine Learning and give students a high-level view of the complete Machine Learning workflow.
>
> By the end of the week, students should understand what Machine Learning is, what problems it is designed to solve, how different types of ML problems are categorized, and what happens from receiving a dataset to evaluating a trained model.

#### Topics & Concepts

##### Machine Learning Fundamentals
- What is Machine Learning?
- Traditional Programming vs. Machine Learning
- When should we use Machine Learning?
- Basic ML terminology:
  - Dataset
  - Sample / Instance
  - Feature
  - Target / Label
  - Model
  - Training
  - Prediction / Inference

##### Types of Machine Learning
- Supervised Learning
- Unsupervised Learning
- High-level examples of each

##### Supervised Learning Problems
- Regression
- Classification
- Real-world examples
- How to identify the problem type

##### Machine Learning Workflow
- Problem Definition
- Data Collection
- Data Understanding
- Data Preparation
- Dataset Splitting
- Model Selection
- Training
- Validation / Evaluation
- Model Improvement
- Final Testing
- Deployment / Inference — high-level only

##### Dataset Splitting
- Training Set
- Validation / Development Set
- Test Set
- Why we need each one
- Data leakage — introductory concept only
